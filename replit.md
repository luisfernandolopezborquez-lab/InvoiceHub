# Facturia

A client-side invoice generator built with Next.js 16, React 19, Tailwind CSS v4, and `@react-pdf/renderer`. Users fill out an invoice form, see a live preview, and can download a PDF. Data is auto-saved to `localStorage`.

## Stack

- **Framework:** Next.js 16 (App Router)
- **UI:** Tailwind CSS v4, shadcn/ui components
- **PDF:** @react-pdf/renderer
- **Package manager:** pnpm

## Running the app

```bash
pnpm dev --port 5000
```

The workflow "Start application" runs this automatically.
